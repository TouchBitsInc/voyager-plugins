# Voyager Media Plugin

Releases of the Voyager Media Plugin, the companion app that brings video playback and downloads to Voyager.

Download the latest DMG from [Releases](https://github.com/TouchBitsInc/voyager-media-plugin/releases/latest), open it, and drag the app to Applications. Installed copies update themselves through Sparkle.

This repository holds only the release files; the source lives elsewhere.
